🚀 INSTALACIÓN Y EJECUCIÓN
───────────────────────────────────────────────────────────────

1. INSTALAR DEPENDENCIAS (ejecutar UNA SOLA VEZ):
   
   npm install

   Esto instalará:
   • Componentes de Radix UI
   • Shadcn UI components
   • Tailwind CSS 4
   • React 19
   • Otros paquetes necesarios

2. INICIAR SERVIDOR DE DESARROLLO:

   npm run dev

   La app se abrirá en: http://localhost:5173

3. COMPILAR PARA PRODUCCIÓN:

   npm run build

   Genera carpeta 'dist' optimizada

4. VER PREVIEW DEL BUILD:

   npm run preview

🎯 PERSONALIZACIÓN
───────────────────────────────────────────────────────────────

AGREGAR PERSONAJES:
  1. Abre: src/lib/characters.ts
  2. Agrega un nuevo objeto en el array
  3. Completa: id, name, role, image, bio, power, race, saga, techniques

CAMBIAR COLORES:
  - Edita: src/index.css
  - Variables CSS:
    --primary: Para botones y acentos
    --secondary: Para secundarios
    --destructive: Para alertas

EDITAR ANIMACIONES:
  - Archivo: src/components/HomePage.css
  - Modifica keyframes y timing


💡 TIPS Y TRUCOS
───────────────────────────────────────────────────────────────

• Haz clic en cualquier tarjeta de personaje para ver detalles
• Pasa el mouse sobre los badges para ver tooltips
• La búsqueda es instantánea
• Todo es totalmente responsivo en móvil
• Los estilos oscuros son tema por defecto
• Las animaciones se optimizan en navegadores antiguos


🐛 TROUBLESHOOTING
───────────────────────────────────────────────────────────────

Error: "cannot find module '@radix-ui'"
  → Solución: npm install

Error: "TypeScript compilation failed"
  → Solución: npm run lint

Error: "blank page"
  → Solución: Limpia caché: npm run dev --reset-cache

El servidor no inicia:
  → Puerto 5173 ocupado: npm run dev -- --port 3000
